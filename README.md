# विकीलिंक सहायक (WikiLink Assistant)
### विकिपीडिया तार्किक आंतरिक कड़ी योजक उपकरण (Logical Wikilinker Tool for Wikipedia)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![License: CC BY-SA 4.0](https://img.shields.io/badge/License-CC_BY--SA_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by-sa/4.0/)
[![Wikipedia: Linking](https://img.shields.io/badge/Wikipedia-WP%3ALINK-green.svg)](https://hi.wikipedia.org/wiki/विकिपीडिया:कड़ियां)
[![Zero Login](https://img.shields.io/badge/Login-Zero_Login_Privacy-brightgreen.svg)](#बिना-लॉगिन-संरचना)

**विकीलिंक सहायक (WikiLink Assistant)** एक स्वतंत्र, मुक्त-स्रोत उपकरण वेबसाइट है जो किसी भी चुनी हुई भाषा के विकिपीडिया लेख में **तार्किक आंतरिक कड़ियाँ (Wikilinks)** स्वतः पहचानने, जोड़ने और उनकी समीक्षा करने की सुविधा प्रदान करती है। यह उपकरण लोकप्रिय विकिमीडिया टूल **[reFill](https://refill.toolforge.org/)** की शैली में डिज़ाइन किया गया है।

---

## 🌟 मुख्य विशेषताएँ (Key Features)

1. **🌐 व्यापक बहुभाषी समर्थन (Multi-language Wikipedia Support)**:
   - हिन्दी (`hi`), संस्कृतम् (`sa`), भोजपुरी (`bho`), मैथिली (`mai`), मराठी (`mr`), বাংলা (`bn`), ગુજરાતી (`gu`), ਪੰਜਾਬੀ (`pa`), தமிழ் (`ta`), తెలుగు (`te`), اردو (`ur`), English (`en`) सहित किसी भी विकिपीडिया भाषा कोड का सीधा समर्थन।

2. **🧠 तार्किक कड़ी पहचान (Logical Linking Engine)**:
   - **प्रथम उल्लेख नियम (First Occurrence Rule)**: विकिपीडिया नियमावली ([WP:OVERLINKING](https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style/Linking#Overlinking_and_underlinking)) का पालन करते हुए एक लेख में किसी शब्द/विषय की कड़ी केवल उसके पहले उल्लेख पर बनाता है।
   - **विकिपीडिया संरचनाओं की पूर्ण सुरक्षा**: टेम्पलेट्स (`{{...}}`), संदर्भ (`<ref>...</ref>`), अनुभाग शीर्षक (`== ==`), श्रेणियाँ (`[[Category:...]]`), चित्र/फ़ाइलें (`[[चित्र:...]]`), और कोड ब्लॉक्स (`<code>`, `<nowiki>`) के भीतर कोई छेड़छाड़ नहीं करता।
   - **स्टॉपवर्ड्स व व्याकरणिक पद निष्कासन**: भाषा-विशिष्ट आम सर्वनाम, सहायक क्रियाओं और अव्ययों (है, था, और, का, के, में, से आदि) को स्वतः बाहर रखता है।
   - **बहु-शब्द वाक्यांश (n-grams) प्राथमिकता**: बड़े वाक्यांशों को एकल शब्दों से पहले प्राथमिकता देता है (उदा: 'भारतीय राष्ट्रीय कांग्रेस' पहले, 'कांग्रेस' बाद में)।

3. **🔍 विकिपीडिया Action API द्वारा लाइव सत्यापन**:
   - उम्मीदवार पदों का विकिपीडिया API द्वारा बैच सत्यापन (Batch Querying)।
   - **🔵 नीली कड़ियाँ (Blue Links)**: जो लेख विकिपीडिया पर वास्तव में मौजूद हैं।
   - **🟢 पुनर्निर्देशन (Redirects)**: पुनर्निर्देशन को स्वतः प्रमाणित मुख्य पृष्ठ के लक्ष्य में परिवर्तित करना।
   - **🔴 लाल कड़ियाँ (Red Links)**: अस्तित्वहीन लेखों को फ़िल्टर करने या छोड़ने का विकल्प।

4. **📊 reFill-शैली संवादात्मक समीक्षा पटल (Interactive Review & Diff)**:
   - प्रत्येक सुझाई गई कड़ी के लिए चेकबॉक्स (इच्छानुसार चयन या अस्वीकार)।
   - संदर्भ पूर्वावलोकन (Context snippet with highlights)।
   - इनलाइन लक्ष्य संपादन मोडल (कड़ी का लक्ष्य बदलने हेतु)।
   - **डिफ़ दृश्य (Diff View)**: जोड़े गए विकिटेक्स्ट का स्पष्ट रंगीन डिफ़।
   - **पूर्वावलोकन (Rendered Preview)**: विकिपीडिया लेख के समान पूर्वावलोकन।
   - **संशोधित विकिटेक्स्ट (Wikitext Output)**: कॉपी करने हेतु तैयार विकिटेक्स्ट।

5. **🔒 बिना लॉगिन - स्वतंत्र एवं सुरक्षित उपकरण (Zero-Login / Privacy First)**:
   - चूँकि बाहरी वेबसाइट से विकिपीडिया पर सीधे संपादन हेतु विकिमीडिया फ़ाउंडेशन के साथ OAuth 2.0 कंज्यूमर पंजीकरण आवश्यक होता है, अतः किसी भी अनधिकृत या असुरक्षित लॉगिन का विकल्प नहीं रखा गया है।
   - उपयोगकर्ता अपने जोड़े गए बदलावों को **1-क्लिक विकिटेक्स्ट कॉपी** बटन से सुरक्षित रूप से कॉपी कर सीधे विकिपीडिया के संपादन पृष्ठ पर सुरक्षित कर सकते हैं।

## 🚀 उपकरण चलाने की विधि (How to Run)

### विधि 1: शून्य-निर्भरता स्थानीय सर्वर (अनुशंसित)
यह टूल Python की मानक लाइब्रेरी के साथ चलता है (किसी बाहरी पैकेज की आवश्यकता नहीं):

```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/vikrampratap-wiki/wikilink-tool.git
cd wikilink-tool

# सर्वर चलाएँ (ब्राउज़र स्वतः खुल जाएगा)
python3 server.py
```
डिफ़ॉल्ट रूप से सर्वर `http://localhost:8085` पर आरंभ होगा।

### विधि 2: त्वरित शैल स्क्रिप्ट
```bash
./open_tool.sh
```

### विधि 3: सीधे ब्राउज़र में खोलें
बिना किसी सर्वर के भी केवल `index.html` फ़ाइल को अपने किसी भी वेब ब्राउज़र (Chrome, Firefox, Edge) में सीधे खोलकर उपयोग कर सकते हैं।
